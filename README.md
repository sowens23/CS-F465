  - [Schneier on Security](https://www.google.com/url?q=https://www.schneier.com/&sa=D&source=editors&ust=1782939134063161&usg=AOvVaw0W3rbWaw0yIDJvl70sUuzE): good summary of security news in a social context from a technical person.
